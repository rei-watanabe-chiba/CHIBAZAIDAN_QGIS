# FEAT-04: 図面出力・エクスポート処理

打刻済みポイントデータをCSVとして出力・エクスポートする際の制約を定義する。

## 1. 破壊不可制約 & ビジネスルール (Invariants)
* **【無選別フルダンプ制約】**: エクスポート処理は、UIで対象図面が選択されていてもフィルタリングを行わず、現在保持している全てのポイントをレイヤから無条件でダンプすること。
* **【スキーマとフォーマットの固定化】**: 出力項目は「出土形態, 遺構名, 属性, 点名, 枝番, Ｘ座標(南北), Ｙ座標(東西)」の 7 項目固定とする。また、座標値は測量座標系に変換の上で小数点以下3桁にフォーマットして出力する。
* **【エンコーディングの選択式】**: CSVの文字コードは固定せず、UIで適切なエンコーディングから選択可能にする。
* **【測量座標への逆変換】**: データベース内に保持されている数学座標を、出力直前の境界で座標変換処理を使って測量座標（X軸=南北, Y軸=東西）へ逆変換してからCSVに書き出すこと。
* **【未計算のハードブロック】**: 出力対象のポイント群の中に、座標変換が完了していない（実座標がNULL）点が1つでも存在する場合、警告を表示してCSV出力処理全体をハードブロックする。

##### 2. 状態・排他制御ルール
* **出力前バリデーション**: 出力実行時、現在のプロジェクト内の全点をスキャンする。未計算（基準点が未確定で実座標値が存在しない等）のフィーチャが1件でも含まれる場合、全体のエクスポート処理を中断して警告を出す。CSV出力のドメイン層の関数はダイアログを表示せず、失敗理由（打刻点なし・実座標未取得の件数・書込みエラー）をメッセージとして返すのみとし、ダイアログでの通知はView側が処理完了後に行う（保存先パスが未指定の場合は、ダイアログを出さず、パス入力欄へのフォーカス移動のみで通知する）。通知後はエラー状態を解除する。
