# FEAT-05: レイヤ管理・同期・バリデーション防御機構

非同期・リアルタイムに稼働するデータストア操作に対し、無限ループや不整合を防ぐための静的およびリアルタイムバリデーションの制約を定義する。

## 1. 破壊不可制約 & ビジネスルール (Invariants)
* **【独自アトミック同期 (対象図面)】**: UIからのレイヤ名変更・削除時、基盤システムの標準イベントに依存せず、独自処理で対象図面を示す属性をバックグラウンドで一括置換・クリアし状態乖離を防ぐ。
* **【トランザクション中の操作ロック】**: 変換確定や一括更新など重い処理中はユーザー入力を無効化（待機状態化）し、割り込みを防ぐ。
* **【自己除外スキャン】**: データ名のリアルタイム重複チェック時は、現在編集中の対象自身の識別子を検索対象から除外し、自己重複の誤検知を防ぐ。
* **【特定属性専用入力バリデーション】**: 特定のテキスト入力領域にはシステムレベルの入力制約を適用し、許可された文字形式以外を強制ブロックする。
* **【エラー時のコミット遮断】**: 必須項目未指定や重複エラー検知時は内部状態を更新し、リアルタイムのデータ保存をすべて遮断する。
* **【無限ループの抑止】**: 既存データ選択によるUIへのロード時は、イベント発火による再帰的なデータ書き込みを防ぐため、内部的な仕組みでイベント連鎖を断ち切る。
* **【ステートの強制的クリーンアップ】**: 既存データを編集状態のまま新規作成モードに切り替えた際、選択状態の識別子を強制リセットし、誤った自己除外状態の残留を防ぐ。
* **【打刻点レイヤの動的マイグレーション】**: レイヤ初期化・読み込み時に `check_and_migrate_point_layer` が走り、`drawing_name`, `pixel_x`, `pixel_y` などの必須カラムが欠落していれば自動追加される。
* **【インメモリキャッシュのObserverパターン同期】**: `QgsSpatialIndex` と属性・ジオメトリのインメモリキャッシュが構築され、レイヤの `featureAdded`, `featuresDeleted`, `attributeValueChanged`, `geometryChanged` シグナルを常時監視してバックグラウンド同期される。

## UI/UX ライフサイクル制約 (防衛機構)

本セクションでは、アプリケーションのライフサイクル制御に定義されている防衛機構に関する制約を重複・集約して記載します。

### モードレスダイアログ展開時のサスペンド
* **ダイアログ排他制御**: いずれかのダイアログが開いている間は、メイン画面での対話型ツールを強制的に解除し、誤操作を防ぐ。
* **トランザクション中の操作ロック (UX視点)**: 出力、名前変更、削除などの重いI/O操作中は、マウスポインタが待機状態になり、画面上のあらゆるクリックや操作が一時的にブロックされ、ユーザーによる非同期の割り込みを物理的に防ぐ。

### エラー時のシグナル遮断・サイレントブロック
* **エラー時の入力ブロック**: 必須項目未指定や重複エラーが発生している間は、UIパネルがエラー表示になり、画面上からの新規入力および既存データのリアルタイム更新が強制的にブロックされる。
* **ロード時イベント抑止**: 既存データ展開時の無限ループを避けるため、UIへの値セット中はイベント通知を無効化する仕組みを用いて一時的にイベントを遮断する。
