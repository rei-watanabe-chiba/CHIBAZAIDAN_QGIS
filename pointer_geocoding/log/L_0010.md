# L-0010: 3点以上指定時の非せん断アフィン変換（最小二乗法）の実装

## 概要
アナログ図面（スキャン紙図面）の座標変換において、3点以上の基準点を指定した際に、クリック時の手ブレ（1〜2px）が斜め歪み（せん断/Shear）として誤吸収され、図面外挿部の座標が暴走する問題がありました。これを解決するため、NumPyとSciPyを用いた「5パラメータ非せん断アフィン変換（最小二乗最適化）」アルゴリズムへ改修しました。

## 変更内容
1. **変換アルゴリズムの刷新** (`src/logic/transform.py`)
   - `CoordinateTransformer.compute_affine_points` において、基準点数が3点以上（N>=3）の場合の処理を改修しました。
   - 従来の「自由度0の6パラメータアフィン変換」を廃止し、異方性スケール・回転・平行移動のみを許容する「5パラメータ非せん断アフィン変換」を導入しました。
   - `scipy.optimize.least_squares` を用いて手ブレ誤差を最小二乗法で平滑化するロジックを実装しました。

2. **戻り値（インターフェース）の互換性維持** (`src/logic/transform.py`)
   - 算出された5パラメータ（Sx, Sy, θ, Tx, Ty）から、従来の一次変換式（X = Ax + By + C, Y = Dx + Ey + F）に対応する6要素に再展開する処理を追加しました。
   - これにより、システムの他モジュール（ワールドファイル出力や逆変換など）に影響を与えることなく、常に互換性のある `(A, B, C, D, E, F)` のタプル形式で結果を返却する仕様を厳守しました。

3. **設計行列構築時のバグ修正** (`src/logic/transform.py`)
   - デバッグ過程において判明した、初期値推定時の `np.linalg.lstsq` における `Incompatible dimensions`（次元不一致）エラーを修正しました。目的変数ベクトル（`b_aff`）への実座標（X, Y）の追加漏れを解消しています。

## 確認結果
ユーザーによるQGIS環境での動作確認が完了し、3点および4点以上の基準点設定時においてエラーが発生せず、安定して計算処理が完了することを確認しました。せん断を排除したことにより、物理的な紙図面の特性に即した高精度な座標変換が実現されました。
