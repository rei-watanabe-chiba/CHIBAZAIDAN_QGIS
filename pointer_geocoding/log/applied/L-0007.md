# L-0007: 遺構管理UI改修 (FEAT-01) と防衛策の実装

## 1. 概要
既存の「遺構名作成」ダイアログとドック上のカラー・遺構名入力を統合し、一覧表示と編集が可能な「遺構管理ダイアログ」へと移行。また、遺構名の未登録状態を明示し、メインキャンバスでの打点時にエラーとしてハンドリングする堅牢なバリデーションを導入した。

## 2. 変更対象ファイルと主な実装内容
* **src/ui/constants.py:**
  * `FEATURE_MANAGE`、`FEATURE_MANAGE_DIALOG_TITLE`、`UNREGISTERED` などの UI ラベルおよびバリデーション用の定数を追加。
* **src/ui/dialogs.py:**
  * 既存の `FeatureCreateDialog` をリファクタリングして `FeatureManageDialog` を実装。
  * リスト一覧 (`QTableWidget`) にて、既存の遺構の管理（名前変更・カラー変更）と新規作成機能を統合。
* **src/ui/tab2_plot.py:**
  * 属性パネルのUIを刷新（不要なカラーピッカーの削除、ボタンのリネーム）。
  * 遺構管理のコールバックメソッド `_rename_and_recolor_feature` の追加と、ダイアログからの安全な一括更新ロジックを実装。
  * `UNREGISTERED` の未選択チェックをバリデーションに追加。

## 3. 導入された防衛策・バリデーション
* **UI更新のシグナル遮断:** `_rename_and_recolor_feature` 実行中に `self._suppress_realtime_commit = True` のフラグを適用し、意図せぬリアルタイムコミットを防止。
* **ダイアログ内のイベントループ遮断:** `FeatureManageDialog` の更新処理中に `QTableWidget` の `blockSignals(True)` を用いて、選択状態変更イベントの暴発を防ぐようにした。
* **文字サニタイズ:** `QLineEdit` に対して FEAT-05 準拠の `QRegularExpressionValidator` を設定し、不正な文字入力をUIレイヤーでブロック。

ユーザーによる動作確認が完了し、安定動作が確認された。
