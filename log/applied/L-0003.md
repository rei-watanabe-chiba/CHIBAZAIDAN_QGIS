# 改修ログ L-0003: 対象図面 (drawing_name) 変更可能化と空間バリデーションの実装

## 概要 (Overview)
FEAT-01における「対象図面の不変性（Drawing Lock）」制約を撤廃し、既存点の編集時に所属図面（`drawing_name`）を変更できるように改修しました。
図面の変更に伴う「未変換図面への割り当てによる座標消失（テレポートバグ）」や「空間的に離れた図面への割り当てによる相対座標の暴走」を防ぐため、「未指定」状態の追加と、画像の実ピクセル寸法（`width`, `height`）を用いた厳密な空間バリデーション機構を新たに実装しました。

## 実施日 (Date)
2026-09-18

## 変更内容詳細 (Changes)

### `src/ui/constants.py`
- `UILabels.DRAWING_UNSPECIFIED` ("-- 未指定 --") を追加しました。
- `UILabels.STATUS_ERR_OUT_OF_BOUNDS` ("図面範囲外") を追加しました。

### `src/ui/tab2_plot.py`
- **ロック解除**: `_CATEGORY_LOCK_WIDGET_NAMES` を空にし、編集モード時に対象図面のコンボボックスが操作できるようにしました。
- **未指定の追加**: コンボボックスの先頭に `-- 未指定 --` を動的に追加するよう `_update_drawing_combo` を改修しました。
- **空間バリデーション (`_validate_drawing_bounds`)**: 
  - 選択された図面の `QgsRasterLayer` から寸法を取得し、逆算したピクセル座標が `0 <= px <= width` かつ `0 <= py <= height` の範囲内に収まっているかを判定する新規メソッドを追加しました。
  - アフィンパラメータが存在しない未変換図面への割り当ては範囲外として弾く仕様としました。
- **リアルタイムエラー検知**:
  - `_check_realtime_out_of_bounds` を追加し、編集モードで図面を切り替えた際に既存点のジオメトリが新図面の範囲内に収まるかをチェックするようにしました。
  - `_update_point_info_status` にエラー表示ロジックを統合し、範囲外の場合は「図面範囲外」の赤枠エラーを表示してDB保存（リアルタイムコミット）を遮断するようにしました。
- **座標の逆算保存**:
  - `_commit_attribute_fields_if_editing` において、対象図面が変更されかつバリデーションを通過した場合に限り、新図面のアフィンパラメータを用いて `pixel_x`, `pixel_y` を再計算・更新してDBへコミットする処理を追加しました。
- **新規打刻ブロック**:
  - 新規フィーチャ生成（打刻）の直前にも空間バリデーションを適用し、画像範囲外のクリックを無効化する防御機構を追加しました。

### `docs/FeatureArchitecture.md`
- FEAT-01の「破壊不可制約 2. 所属図面の不変性 (Drawing Lock)」を「対象図面変更時の空間的整合性制約」へと更新し、空間バリデーションによって整合性を担保する新しい設計ルールを明記しました。
